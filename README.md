## Objective
Use structured prompts to create a UGC (User Generated Content) ad pack: short, natural-sounding ad scripts, scroll-stopping hooks, CTAs and captions for one business, adapted for different platforms.

## Business used
**Sweet Crumbs Home Bakery** (sample business), Salem. Custom birthday cakes, cupcake boxes, eggless options. Brand type: local business. Tone: warm, friendly, real.

*This is a sample business created for practice.*

## What is in the ad pack
| Item | Count |
|---|---|
| Hooks | 6 |
| Full ad scripts (Problem, Solution, CTA) | 3 |
| Platform versions (Instagram, Facebook, YouTube Shorts) | 3 |
| Captions with CTA | 3 |

## Workflow
```
Understand product -> Write structured prompt -> Generate hooks -> Write scripts -> Adapt per platform -> Review -> Refine -> Save prompt + output
```

## Key learnings
- The first 3 seconds (hook) decide whether people keep watching, so I generated many hooks for the same product and picked the best.
- A UGC ad should sound like a real customer talking, not like a company announcement.
- Problem, Solution, CTA structure keeps a 30-second script clear.
- Each platform needs a different length and caption style.
- No fake claims (no invented reviews, discounts or "best in Salem").
